Сборка подписана для распространения через App Store, поэтому установить её на телефон напрямую нельзя: такие файлы ставятся только через TestFlight или App Store. Файл хранится как эталон того, что ушло на проверку. Новые сборки делаются скриптом `scripts/archive-ios.sh`, результат в `build/ios/export`.
