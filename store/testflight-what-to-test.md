# Что тестировать в сборке 1.1.0 (4)

Два текста: короткий — для поля «Что тестировать» в TestFlight (App Store Connect → TestFlight → группа → сборка → «Информация о тестировании»), полный — чек-лист для тестировщиков.

## Короткий текст для TestFlight

```
Версия 1.1: свои привычки. Проверьте, пожалуйста:
1. Настройки → «Добавить свою привычку»: название, значок, цвет, что считать, виды срыва. Привычка появляется на главном экране.
2. Главный экран: при 4+ привычках вкладки прокручиваются, свайп между страницами работает.
3. «Был срыв» у своей привычки: виды (если задали), количество или сумма денег, заметка.
4. Достижения: свайп между привычками, поздравление с вехой у своей привычки.
5. Календарь: фильтр по своей привычке, цвет дня, итог за месяц.
6. Клавиатура: при вводе названия или заметки окно не уезжает за верх экрана.
7. Данные из версии 1.0 сохранились (даты, срывы, достижения).
Если что-то не так — модель iPhone, что делали, что ожидали, скриншот.
```

## Полный чек-лист

Отмечайте результат и, если что-то не так, пишите: модель iPhone, версия iOS, шаги, что ожидали, что получили, скриншот.

### 0. Обновление с версии 1.0
- [ ] Поставить 1.1 поверх 1.0 (не удаляя приложение). Даты отказа, срывы, достижения и язык на месте.
- [ ] Главный экран открывается на той же привычке, что и раньше.

### 1. Своя привычка
- [ ] Настройки → «Добавить свою привычку» → сначала спрашивает дату отказа, потом открывает форму.
- [ ] Без названия сохранить нельзя, подсказка «Введите название».
- [ ] Значок подбирается сам по названию (например, «кофе» → чашка, «ставки» → кости, «сериалы» → экран); его можно сменить вручную.
- [ ] Цвет из палитры, единица счёта (разы, штуки, порции, минуты, деньги), виды срыва через запятую.
- [ ] Новая привычка появилась в настройках со своим значком, на главном экране и в календаре.
- [ ] «Своя привычка → Изменить» меняет название, значок, цвет, единицу, виды; старые срывы остаются.
- [ ] «Удалить привычку» спрашивает подтверждение и удаляет привычку вместе с её срывами.
- [ ] Шестую привычку добавить можно, седьмую нет: вместо кнопки надпись «Можно вести не больше 6 привычек».
- [ ] Встроенные «Алкоголь» и «Курение» удалить нельзя, только выключить; последнюю включённую выключить нельзя.

### 2. Первый запуск (на чистой установке или после «Сбросить все данные»)
- [ ] На шаге выбора привычек есть «Добавить свою привычку», своя привычка показывается карточкой.
- [ ] Нажатие на карточку своей привычки открывает правку, в форме есть «Удалить».
- [ ] На шаге дат есть карточка своей привычки; после «Готово» всё появляется на главном.

### 3. Главный экран
- [ ] До трёх привычек — переключатель-сегменты в шапке; от четырёх — название «Чистый счёт» и строка вкладок с цветными точками ниже.
- [ ] Свайп между страницами и нажатие на вкладку согласованы.
- [ ] У своей привычки карточка в её цвете, подпись — название привычки.
- [ ] «Срывы»: чипы видов появляются только для видов, которые встречались; без видов — просто число.

### 4. Запись срыва
- [ ] Своя привычка с видами: нужно выбрать вид, иначе «Записать» неактивна.
- [ ] Своя привычка без видов: блок «Что это было» не показывается.
- [ ] Единицы: «разы/штуки/порции/минуты» — счётчик «−/+», «деньги» — поле суммы (без суммы записать нельзя).
- [ ] Заметка есть у всех привычек, включая курение.
- [ ] «Отменить» в сообщении «Срыв записан» возвращает всё как было.

### 5. Календарь
- [ ] Вкладки «Все» и по привычкам (с цветными точками); при 4+ привычках строка прокручивается.
- [ ] День со срывом своей привычки окрашен её цветом; два срыва разных привычек в один день — диагональ из двух цветов.
- [ ] Нажатие на день показывает срывы с названием привычки и видом; долгое нажатие удаляет.
- [ ] Итог за месяц: плитка на каждую видимую привычку, при 3+ плитках они переносятся в два ряда.

### 6. Достижения и вехи
- [ ] Вкладки сверху и свайп между привычками, как на главном экране.
- [ ] Поздравление «Новая веха!» появляется у своей привычки в её цвете с подписью «дней без срывов · Название».
- [ ] После закрытия поздравления срывы и достижения не пропадают (откройте календарь и проверьте).

### 7. Клавиатура и размеры экрана
- [ ] В форме привычки и в заметке к срыву при появлении клавиатуры окно ужимается, заголовок остаётся виден, поле ввода над клавиатурой.
- [ ] На iPhone с меньшим экраном (например, 13 mini, SE, 15, 16e) экраны выглядят как на 14 Pro Max, только пропорционально меньше; ничего не обрезано.
- [ ] Крупный системный шрифт (Настройки iPhone → Экран и яркость → Размер текста): тексты не наезжают друг на друга.

### 8. Язык
- [ ] Переключение «Русский/English» в настройках меняет все подписи; названия своих привычек и их видов остаются как введены.
